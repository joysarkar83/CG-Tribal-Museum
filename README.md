# Chhattisgarh Tribal Museum & Freedom Fighter Museum

This project is a multi-page digital museum website developed to present the cultural heritage, tribal history, and freedom fighter narratives of Chhattisgarh.
This was built in collaboration with the actual **C.G. Tribal Museum and Shaheed Veer Narayan Singh Memorial and Tribal Freedom Fighters Museum** as a minor project for my 3rd Semester.
It is built using **HTML, CSS, and JavaScript** and structured to support long-term institutional deployment on government infrastructure.

## Project Objective

To provide a structured, accessible, and visually engaging digital platform for:
- Tribal cultural representation
- Artifact and gallery showcases
- Freedom fighter documentation
- Institutional vision and messaging

The architecture prioritizes stability, clarity, and maintainability over experimental frameworks.

---

## Architecture Overview

- Multi-page static website
- Each section is modular and self-contained
- No framework or build tools required
- Designed for CDN / government server hosting

---

## Tech Stack

- HTML5 – semantic structure
- CSS3 – layout and responsive design
- JavaScript – client-side interactivity

---

## Key Sections
- About
- Home / Index
- About the Museum
- Vision
- Artifacts Gallery
- Tribal Homepage
- Tribal Gallery
- Freedom Fighter Homepage
- Freedom Fighter Gallery
- Freedom Fighter Collection
- Message

Each section maintains its own HTML, CSS, and JS files for clean separation of concerns.

---

## Running Locally

1. Clone the repository
2. Open `index.html` in any modern browser
3. No build steps or server required

---

## Design Philosophy

- Content-first development
- Accessibility and clarity over complexity
- Long-term maintainability for institutional use
- Compatibility with government hosting constraints
